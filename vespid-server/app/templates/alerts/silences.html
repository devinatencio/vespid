Example: Silence a specific alert on a host

To silence an alert you typically need two matchers — one to match the alert name and one to match the target host:

LabelOpValue
alertname=HighCpuUsage
host=web-prod-01

This silences the "HighCpuUsage" alert only on host "web-prod-01". Without both conditions, the silence would be too broad — either matching all alerts on that host or matching that alert across all hosts.
